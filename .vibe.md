Ping RU — Android-приложение и виджет, который из России каждые 15 минут проверяет доступность интернета отдельно по Wi-Fi и по мобильной сети и пишет историю в график за 24 часа.

Стек: Kotlin, Android (minSdk 26), Material 3, AppWidgetProvider, WorkManager для разовых проверок, AlarmManager.setAndAllowWhileIdle для периодики, ConnectivityManager.requestNetwork для cross-transport probe, SharedPreferences. Сборка debug-APK через GitHub Actions.

Сейчас в фокусе: добавили категорию хостов «в фокусе РКН» (телеграм, ютуб, инстаграм) для мониторинга ослаблений блокировок; перепилили виджет на нативные RemoteViews с тремя строками Wi-Fi/Mobile/РКН; ушли с PeriodicWorkRequest на цепочку AlarmManager, потому что Doze и MIUI рубили ночные проверки.

Особенности: zero-backend, всё локально, без аналитики. Мобилка тестируется даже когда телефон на Wi-Fi — через отдельный сокет requestNetwork(TRANSPORT_CELLULAR). HEAD-проверки на 443, TLS-фейл считается за DPI-блокировку.
